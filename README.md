# O-LABO
スマホ・タブレット・パソコンに対応する、ブラウザ型リバーシ(オセロ)ゲーム。<br><br>
現在日本語のみ対応。<br>
### [O-LABO Wikiを開く](https://github.com/wh949/o-labo/wiki)
# 特徴
複数人でのプレイにも一人でのプレイにも対応！<br><br>
### 複数人で遊べるモード<br>
- **対戦モード**<br>
その場にいる人と対局ができる！<br><br>
- **オンラインモード**<br>
離れた人とでも対局ができる！<br><br>
### 一人で遊べるモード<br>
- **特訓モード**<br>
自分に合った難易度のAIと戦うことで自分のオセロレベルがアップ！<br><br>
- **ゆるモード**<br>
一人でゆるっとリバーシ！...と思いきや、解禁要素もあるみたい...？<br><br>
- **バラエティモード**<br>
バラエティに富んだ特殊ルールでリバーシを遊ぼう！<br><br>
### これから実装予定のモード
- **ストーリーモード**<br>
勇者と魔王、それぞれ正反対の二人の別々のストーリーをリバーシで勝ち進もう！<br><br>
- **カフェ**<br>
O-LABOゲーム内で聞ける音楽や、ストーリーモード内の写真や動画を見れるモード。<br><br>
